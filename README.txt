This is a scheduling website for BYU with the functionalities of making an account and a schedule associated with the account
with an additional edit page for that schedule. It also has administrator functions that allow for checking schedule and 
approving them.

The important links are...
/ (home page)
/account (if the user is an admin it will show all of the accounts in the system)
/account/schedule (a static view of the schedule)
/account/schedule/edit (schedule editor page)
/account/login (login to the account)
/account/signup (create an account)
/account/signup/admin (create an admin account)
/admin/schedules/approvals (approval page for the schedules)
